# Проверка комплекта

Проверено 13 октября 2026 года в Windows. Итоговый №15 использует SQLite из №11; ранняя версия AsyncStorage заменена.

| Проверка | №15 Shopping List Paper | №16 My Places |
|---|---|---|
| TypeScript `tsc --noEmit` | PASS | PASS |
| Автоматические тесты Node | 22/22 PASS, включая настоящий SQLite и web-адаптер | 5/5 PASS, включая настоящий SQLite и геокодирование |
| Expo export | Android и Web — PASS после исправления UI | Android, iOS и Web — PASS |
| Поиск общим запускателем | Обнаружен как Expo | Обнаружен как Expo |
| Браузерное поведение | Добавление Tomatoes/5 kg, сохранение после reload, удаление, повторный reload — PASS | Пустой ввод, реальный Photon-поиск, выбор адреса, сохранение, карта с маркером, Back, reload, удаление — PASS |
| Полные листинги | 14 файлов, сверены с исходниками | 14 файлов, сгенерированы из исходников |

Для №16 реальный адрес `Mannerheimintie 10, Helsinki` найден публичным сервисом; карта и маркер просмотрены в браузере при ширине 390 px. Скриншоты сохранены в `output/playwright/`. Browser localStorage проверяет web-адаптер; работа нативного модуля SQLite на устройстве этой проверкой не подтверждается.

В №15 браузерная проверка выявила блокировку корзины внутри неактивного List.Item. Корзина вынесена отдельным элементом строки; после исправления TypeScript/экспорты и фактическое удаление в браузере проверены повторно. Доменный код и SQL не менялись после успешных 22 тестов.

В №16 `npx expo install --check` подтвердил согласованные зависимости. Bash-синтаксис общего запускателя проверен; его меню нашло оба проекта. Для проверки меню запускатель должен лежать в корне папки, которую он сканирует, поэтому в полном ZIP он есть в корне и в `tools/`.

У архивов проверяются CRC, совпадение байтов с исходниками, соответствие lock-файлов и отсутствие Git, зависимостей, сборок, рабочих БД и секретов. Подробные хеши — в `ARCHIVE-VERIFICATION.json`; дополнительная проверка извлечённых исходников — в `EXTRACTED-VERIFICATION.json`.

Запуск на macOS, iOS Simulator, Android-эмуляторе и физическом устройстве не выполнялся. Полная чистая установка зависимостей из извлечённого ZIP не повторялась; извлечённые исходники проверены отдельным запуском Node-тестов. Ручные сценарии для устройства приведены в мануалах. Bookstore Testing в этот пакет не входит и ведётся в профильном чате.
