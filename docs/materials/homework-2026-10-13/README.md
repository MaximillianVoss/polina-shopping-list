## Как начать

1. Открыть условие нужной работы, затем мануал. В мануале указаны полные листинги файлов и назначение функций.
2. Распаковать проект в `<локальный-путь>`.
3. Запустить его через существующий `build-and-run.sh`, выбрав найденный путь, либо воспользоваться командами прямого запуска из мануала.
4. Выполнить проверки и ручные сценарии. Для сдачи №16 проверить мобильный экран карты и сохранение SQLite на iOS или Android.

№15 можно выполнять прямо в `11-shopping list SQLite/ShoppingListApp`, сохраняя её БД и операции хранения. Если требуется отдельный каталог для сдачи №15, сначала скопировать исходный проект в новую папку. №12 с Firebase для выбранного варианта не требуется.
